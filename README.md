# DaVinciCodeGame

C# 기반으로 제작된 다빈치코드 게임 멀티플레이어 프로젝트입니다. (2025학년도 프로젝트 아카이빙)
이 리포지토리는 사용자 인터페이스(UI)를 담당하는 `Client`와 게임 로직 및 네트워크 통신을 제어하는 `Server`로 구성되어 있습니다.

## 폴더 구조
* `/Client`: C# WinForms 기반의 클라이언트 프로그램 (플레이어용 UI)
* `/Server`: C# Console 기반의 중앙 통제 서버 프로그램 (TCP 9999 포트 사용)

## 특이사항 및 한계점 (Limitations)
추가적인 업데이트는 진행하지 않는 아카이빙용 프로젝트이며, 실행 시 다음 사항들을 참고해야 합니다.

* **네트워크 설정 (하드코딩):** 클라이언트(`Form1.cs`)의 접속 IP가 `"172.20.10.2"`로, 서버(`Program.cs`)의 포트가 `9999`로 고정되어 있습니다. 로컬 환경에서 테스트하려면 코드 수정 후 재빌드가 필요합니다.
* **조커(13) 정렬 방식:** 게임 룰과 달리 조커의 위치를 플레이어가 임의로 지정할 수 없으며, 카드 정렬 시 항상 덱의 맨 오른쪽(가장 큰 수)으로 고정됩니다.
* **스레드 동기화 (Thread Safety):** 서버에서 플레이어들의 입력을 처리할 때 공유 자원(덱, 턴 변수)에 대한 Lock 처리가 되어 있지 않아 동시에 접근 시 충돌 가능성이 있습니다.
* **예외 처리 부재:** 게임 도중 한 플레이어가 비정상적으로 연결을 종료하면 서버 프로세스에 예외가 발생하며 멈출 수 있습니다.
* **실행 환경:** `.NET Framework 4.7.2` 기반으로 작성되어 Mac 환경에서는 네이티브 실행이 불가하며 Windows 환경에서 구동해야 합니다.
